# Bilibili Reader Userscript

供脚本猫、Tampermonkey 等用户脚本管理器使用的 B 站阅读模式。
![alt text](示例图.png)

## 功能介绍

- 阅读模式：将视频播放器、字幕和章节整理为便于连续观看与阅读的界面。
- 字幕阅读：在右侧显示当前视频字幕，并可跟随播放进度定位内容；切换分集后会继续加载并保留字幕面板。
- 章节导航：视频提供章节时，可在阅读视图中查看并点击跳转。
- 合集选集：检测到当前合集包含多个分集时，顶部会展示选集列表；点击任意一集即可切换，范围仅限当前合集，不会跳转到其他合集。
- 标题自适应：主标题和分集副标题位于独立容器中，长文本最多显示两行并自动换行，避免与合集列表重叠或越界。
- 阅读设置：可按需调整阅读界面的主题、字体、字重、字距、行距、内容宽度及章节、时间戳显示方式。

## 安装

本脚本支持 **脚本猫（ScriptCat）**、**Tampermonkey（篡改猴）** 等常见用户脚本管理器。

1. 首先在浏览器中安装 **脚本猫（ScriptCat）** 或 **Tampermonkey（篡改猴）** 扩展。
2. 打开 Bilibili Reader 的 ScriptCat 页面：[https://scriptcat.org/zh-CN/script-show-page/8038](https://scriptcat.org/zh-CN/script-show-page/8038)。

3. 点击页面中的 **“安装脚本”**。
4. 浏览器会自动唤起用户脚本管理器，确认脚本内容后点击 **“安装”**。
5. 安装完成后，打开或刷新任意 Bilibili 视频页面即可使用。

## 使用

1. 打开 B 站视频页面。
2. 点击视频标题区域右侧的“阅读”按钮；也可以从脚本菜单选择“进入阅读模式”。
3. 点击阅读视图右上角的关闭按钮，或从脚本菜单选择“退出阅读模式”。
