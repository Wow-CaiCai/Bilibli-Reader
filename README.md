# 把视频变成“文章”：Bilibili 与 YouTube 阅读模式

## Bilibili Reader：支持哔哩哔哩与 YouTube 阅读模式的浏览器脚本。

在原生播放页阅读连续字幕，或点击字幕工具栏中的翻开书本图标，进入视频、章节和字幕联动的阅读视图。B 站与 YouTube 使用相同位置的按钮切换模式。

## 0.0.10-alpha.7 版本说明

本版汇总 0.0.9 之后的动画调整、性能优化、问题修复和代码整理。

### 使用变化

- **刷新后回到默认播放页**：在阅读模式下刷新页面，会返回默认播放视图；需要继续阅读时，再次点击「阅读」即可进入。
- 移除刷新时自动恢复阅读布局的缓存、提前布局和加载遮罩；挂载播放器时也不再主动隐藏视频画面。

### 优化

- 统一进入和退出阅读模式的动画节奏与过渡路径，让切换体验更一致。
- 字幕、章节和合集列表分别更新，切换字幕语言时减少不必要的章节和合集重绘。
- 复用字幕与章节的处理结果、高亮节点和阅读位置索引，减少播放跟随时的重复计算与页面查找。
- 播放进度跟随与播放器布局分开处理，减少播放期间不必要的尺寸计算。
- 拖动分隔条时合并同一帧内的更新，并在松手时保存最终位置；退出阅读模式或切换视频时会取消未完成的拖动更新。
- 字体、主题、控件和布局数值未变化时跳过重复更新，减少无效的页面写入。
- 页面变化检测集中到播放器、标题和字幕面板等相关区域，减少无关页面内容触发的处理；稳定的监听区域不再反复重建。
- 同一视频正在加载字幕时，进入阅读模式会复用当前加载，减少重复请求。

### 修复

- 修复快速切换字幕语言时，较早的请求覆盖当前选择的问题。
- 修复等待播放器加载期间退出阅读模式、重新进入或切换视频时，旧任务继续影响当前页面的问题。
- 加载或切换字幕时，保持已经稳定的阅读界面，避免标题和按钮重复隐藏、显示。
- 调整字幕样式时保留阅读位置；减少进入阅读模式时重复滚动定位造成的界面漂移。
- 完善播放器更换、模式退出时的事件监听和定时器清理，避免旧播放器回调继续执行。
- 字幕请求无响应时会超时，并尝试备用请求方式，避免一直停留在加载状态。

### 代码与构建整理

- 将阅读会话、布局、播放器适配和页面监听拆成独立模块，按视频数据、阅读会话、偏好、播放器、原生字幕和界面分组管理状态。
- 清理未启用的旧面板、侧栏、导出、Obsidian 和 AI 入口等遗留代码，以及重复布局分支、无用状态和样式。这些清理针对内部代码，当前功能仍以本文「功能」部分为准。
- 清理废弃设置项，保留现有字幕字体和主题等有效偏好。
- API 与字幕请求统一处理，增加超时与备用请求机制；构建运行时模板独立维护。
- 普通构建仅生成当前版本，使用 `--bump` 或 `--release` 才更新版本号。

## 你可能需要？

![阅读视图示例图](docs/images/sample_reader.png)

1. **快速浏览视频内容**：通过字幕快速浏览视频内容，检查视频的含金量。
2. **查找特定内容**:对于较长的视频,当只记得某个关键词时，可以通过字幕快速定位相关片段。
3. **整理学习笔记**：结合视频、章节和连续字幕阅读，梳理重点、记录知识点和复习提纲。

## 功能

- **原生页面字幕**：B 站在“弹幕列表”上方显示字幕面板；YouTube 在推荐区域上方显示字幕面板，推荐视频保留在其下方。字幕默认展开，支持语言、主题、字号和字重设置。
- **模式切换**：点击“字幕”右侧的书本按钮进入阅读模式，在阅读模式中再次点击同位置按钮返回普通模式。刷新页面后回到默认播放视图。
- **连续字幕阅读**：字幕以全文形式显示，播放时高亮当前内容；阅读模式中的当前字幕带有下划线。点击任一句可跳转到对应时间，点击“回到当前字幕”可恢复播放跟随。
- **YouTube 章节**：在阅读模式的视频下方显示已有章节，自动标记当前章节，点击章节可跳转。章节晚于播放器加载时会自动补充；没有字幕也可以使用章节功能。
- **B 站章节与合集**：视频下方显示已有章节；视频属于多分集合集时，顶部显示分集列表，点击即可切换播放。
- **布局调节**：宽屏阅读模式并排显示视频和字幕，拖动两者之间的分隔条可调整宽度；视频保持原始比例，章节区域与视频宽度联动。YouTube 窄屏阅读模式按视频、章节、字幕顺序排列。
- **站内导航**：支持 YouTube 从首页进入视频、切换视频及浏览器前进后退；切换时清理上一视频字幕与章节。离开 YouTube 视频播放页会退出阅读模式。
- **退出阅读**：书本按钮和阅读视图右上角的退出按钮均可返回原生播放页。

### 字幕与章节范围

- B 站字幕来自当前视频可用的字幕轨道。
- YouTube 仅使用视频提供的非自动生成字幕；只有自动生成字幕的视频会显示“当前视频无字幕”，并收起普通模式下的字幕面板。
- 没有可用字幕时仍可进入阅读模式；已有章节独立显示。没有章节的视频不显示章节区域。
- 字幕加载失败时，普通模式的字幕面板提供重试入口。可用字幕语言与章节取决于视频本身。

## 安装

1. 首先在浏览器中安装 **脚本猫（ScriptCat）** 或 **Tampermonkey（篡改猴）** 扩展。
2. 打开 Bilibili Reader 的脚本页面：[脚本猫](https://scriptcat.org/zh-CN/script-show-page/8038) | [Greasy Fork](https://greasyfork.org/zh-CN/scripts/596599-bilibili-reader-%E5%93%94%E5%93%A9%E5%93%94%E5%93%A9%E9%98%85%E8%AF%BB%E6%A8%A1%E5%BC%8F)
3. 点击页面中的 **“安装脚本”**。
4. 浏览器会自动唤起用户脚本管理器，确认脚本内容后点击 **“安装”**。
5. 安装完成后，打开或刷新 Bilibili 或桌面版 YouTube 视频页面即可使用。

也可以在脚本管理器中安装仓库生成的 `Bilibli-Reader.user.js`。更新后刷新视频页面，加载新版本。

## 使用

1. 打开 B 站视频播放页或 `youtube.com/watch?v=...` 页面，等待字幕面板加载。
2. 字幕工具栏从左至右为“字幕”、书本按钮、“回到当前字幕”、主题、语言、字号和字重；普通模式末尾还有展开或收起按钮。
3. 点击书本按钮进入阅读模式。点击字幕句子或视频下方的章节可跳转播放；B 站合集可通过顶部的分集列表切换。
4. 手动滚动字幕会暂时暂停自动跟随；需要回到播放位置时，点击“回到当前字幕”。
5. 点击字幕工具栏中的书本按钮或右上角退出按钮，返回普通播放页。

## 开发与构建

源码按阅读会话、布局、字幕、播放器适配与数据请求拆分；`Bilibli-Reader.user.js` 由构建脚本生成，运行时桥位于 `scripts/userscript.template.js`。

```bash
python3 scripts/build_userscript.py          # 生成当前版本，不修改源码版本号
python3 scripts/build_userscript.py --bump   # 递增 alpha 版本并生成脚本
python3 scripts/build_userscript.py --release # 生成稳定版本
```

构建脚本需要 Python 3.10 或更新版本。

修改源码或 README 后运行构建，同步生成安装脚本和 `docs/README.scriptcat.md`。后者是脚本猫使用的 README，其中本地图片路径会转换为 CDN 地址；请在根目录的 README 中维护说明，再通过构建同步。
