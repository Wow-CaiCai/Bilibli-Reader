# Bilibili Reader 哔哩哔哩阅读视图

供脚本猫、Tampermonkey 等用户脚本管理器使用的[Bilibili](https://www.bilibili.com)阅读模式。
![alt text](示例图.png)
脚本链接：[脚本猫](https://scriptcat.org/zh-CN/script-show-page/8038)


## 你可能需要？

1. **快速浏览视频内容**：通过字幕快速浏览视频内容，检查视频的含金量。
2. **查找特定内容**:对于较长的视频,当只记得某个关键词时，可以通过字幕快速定位相关片段。
3. **整理学习笔记**：将视频字幕导出或复制后，可以进一步提炼重点、整理成笔记、知识卡片或复习提纲。
4. **总结视频内容**：复制文字脚本交给 AI 进行总结，快速了解视频的核心内容、重点知识和整体结构。
   
## 功能

- 合集：当前视频属于多分集合集时，阅读视图顶部显示该合集的分集列表；点击任意分集即可切换播放。
- 字幕：在阅读视图中，当该哔哩哔哩视频自带字幕时，右侧字幕面板会显示当前视频的字幕内容，当前播放的字幕会有下划显示，点击字幕即可跳转到对应的时间点。
- 章节：在阅读视图中，当前视频若有分多个章节时，点击视频下方章节标题即可跳转到对应的时间点。
- 大小调节：通过拖拽调整视频、章节、字幕面板的大小，满足不同用户的使用习惯。
- 设置：阅读视图右上角变换相关主题、退出阅读视图、调整相关设置。

## 安装

本脚本支持 **脚本猫（ScriptCat）**、**Tampermonkey（篡改猴）** 等常见用户脚本管理器。

1. 首先在浏览器中安装 **脚本猫（ScriptCat）** 或 **Tampermonkey（篡改猴）** 扩展。
2. 打开 Bilibili Reader 的脚本页面：[脚本链接](https://scriptcat.org/zh-CN/script-show-page/8038)。

3. 点击页面中的 **“安装脚本”**。
4. 浏览器会自动唤起用户脚本管理器，确认脚本内容后点击 **“安装”**。
5. 安装完成后，打开或刷新任意 Bilibili 视频页面即可使用。
