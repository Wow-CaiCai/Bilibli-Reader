## 0.0.9-alpha.10 预览版说明

### 功能

- 新增进入阅读模式的过渡动画：播放器与字幕面板同时平滑移动到阅读布局，周边信息淡出，过渡时长约 320 毫秒。
- 新增退出阅读模式的过渡动画：播放器平滑回到原页面位置，阅读字幕淡出，原页面渐显，过渡时长约 300 毫秒。
- 支持系统“减少动态效果”设置；浏览器不支持完整过渡动画时，使用简化动画。
- 增加慢加载回退和动画取消处理，避免播放器尚未就绪时一直停留在旧画面。

### 修复

- 修复进入阅读模式后字幕再次滚动的问题：载入时先立即定位当前字幕，再显示过渡动画，正常播放仍保持平滑跟随。
- 优化退出阅读模式的动效衔接：回位时平缓加速、减速，阅读字幕与原页面字幕同步平滑交接。
- 修复退出时视频画面缩到左上角后回弹的问题：捕获外层播放器容器，以固定尺寸快照进行单次平移与缩放，避免宽高动画重复缩放；弹幕输入栏随原页面布局一次性恢复。
- 修正退出时原生播放器尺寸样式的恢复顺序，避免恢复后又被清理。
- 修复退出时右侧字幕栏先消失、再突然出现的问题：在退出动画抓取画面前恢复原页面字幕栏，让两个页面的字幕模板按实际起止位置平移并交叉淡入淡出；进入和退出均保留各模板的尺寸与文字排版，避免缩放文字。
- 修复调整字号、字重或字幕栏宽度时字幕跳动的问题：保留当前可见字幕的位置，调整期间暂停自动跟随，避免文字重排与滚动互相干扰。
- 切换界面前停止尚未结束的字幕滚动，动画期间暂停播放跟随和字幕重绘；动画中改变窗口大小时结束旧过渡，避免继续使用过期位置。
- 切换界面时按字幕索引接续当前阅读位置，并保留手动阅读的自动跟随暂停状态，避免切换后重新跳回播放进度。

## 你可能需要？

![阅读视图示例图](https://cdn.jsdelivr.net/gh/Wow-CaiCai/Bilibli-Reader@main/docs/images/sample_reader.png)

1. **快速浏览视频内容**：通过字幕快速浏览视频内容，检查视频的含金量。
2. **查找特定内容**:对于较长的视频,当只记得某个关键词时，可以通过字幕快速定位相关片段。
3. **整理学习笔记**：将视频字幕导出或复制后，可以进一步提炼重点、整理成笔记、知识卡片或复习提纲。
4. **总结视频内容**：复制文字脚本交给 AI 进行总结，快速了解视频的核心内容、重点知识和整体结构。

## 功能

- 原生页面字幕：原视频页面会自动加载字幕，并在原生“弹幕列表”上方默认展开“字幕”面板；支持切换字幕语言、背景主题、字号和字重，完整连续文本会跟随播放进度标记当前字幕，点击任一句可跳转到对应时间。
- 阅读视图：点击视频右上方的“阅读”按钮即可进入阅读模式。
- 字幕：阅读视图只显示完整连续字幕，当前播放的字幕会有下划显示，点击字幕即可跳转到对应的时间点；可在字幕面板中切换主题、语言、字号和字重。
- 合集：在阅读视图中，当前视频属于多分集合集时，顶部显示该合集的分集列表；点击任意分集即可切换播放。
- 章节：在阅读视图中，当前视频若有分多个章节时，点击视频下方章节标题即可跳转到对应的时间点。
- 大小调节：通过拖拽调整视频、章节、字幕面板的大小，满足不同用户的使用习惯。
- 退出：阅读视图右上角的退出按钮可返回原生播放页。

## 安装

1. 首先在浏览器中安装 **脚本猫（ScriptCat）** 或 **Tampermonkey（篡改猴）** 扩展。
2. 打开 Bilibili Reader 的脚本页面：[脚本猫](https://scriptcat.org/zh-CN/script-show-page/8038) | [Greasy Fork](https://greasyfork.org/zh-CN/scripts/596599-bilibili-reader-%E5%93%94%E5%93%A9%E5%93%94%E5%93%A9%E9%98%85%E8%AF%BB%E6%A8%A1%E5%BC%8F)
3. 点击页面中的 **“安装脚本”**。
4. 浏览器会自动唤起用户脚本管理器，确认脚本内容后点击 **“安装”**。
5. 安装完成后，打开或刷新任意 Bilibili 视频页面即可使用。

## 构建

运行 `python scripts/build_userscript.py` 生成预览版本；运行 `python scripts/build_userscript.py --release` 生成正式版本。两种构建都会更新仓库根目录的 `Bilibli-Reader.user.js`，不再保存按版本命名的副本。
