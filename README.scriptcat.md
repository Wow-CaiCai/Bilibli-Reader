## 你可能需要？

![阅读视图示例图](https://cdn.jsdelivr.net/gh/Wow-CaiCai/Bilibli-Reader@main/sample_reader.png)

1. **快速浏览视频内容**：通过字幕快速浏览视频内容，检查视频的含金量。
2. **查找特定内容**:对于较长的视频,当只记得某个关键词时，可以通过字幕快速定位相关片段。
3. **整理学习笔记**：将视频字幕导出或复制后，可以进一步提炼重点、整理成笔记、知识卡片或复习提纲。
4. **总结视频内容**：复制文字脚本交给 AI 进行总结，快速了解视频的核心内容、重点知识和整体结构。

## 功能

- 原生页面字幕：原视频页面会自动加载字幕，并在原生“弹幕列表”上方默认展开“字幕”面板；支持切换字幕语言、背景主题、字号和字重，完整连续文本会跟随播放进度标记当前字幕，点击任一句可跳转到对应时间。
- 阅读视图：点击视频右上方的“阅读”按钮即可进入阅读模式。
- 字幕：当该哔哩哔哩视频自带字幕时，右侧字幕面板会显示当前视频的字幕内容，当前播放的字幕会有下划显示，点击字幕即可跳转到对应的时间点。
- 合集：在阅读视图中，当前视频属于多分集合集时，顶部显示该合集的分集列表；点击任意分集即可切换播放。
- 章节：在阅读视图中，当前视频若有分多个章节时，点击视频下方章节标题即可跳转到对应的时间点。
- 大小调节：通过拖拽调整视频、章节、字幕面板的大小，满足不同用户的使用习惯。
- 设置：阅读视图右上角变换相关主题、退出阅读视图、调整相关设置。

## 安装

1. 首先在浏览器中安装 **脚本猫（ScriptCat）** 或 **Tampermonkey（篡改猴）** 扩展。
2. 打开 Bilibili Reader 的脚本页面：[脚本猫](https://scriptcat.org/zh-CN/script-show-page/8038) | [Greasy Fork](https://greasyfork.org/zh-CN/scripts/596599-bilibili-reader-%E5%93%94%E5%93%A9%E5%93%94%E5%93%A9%E9%98%85%E8%AF%BB%E6%A8%A1%E5%BC%8F)

3. 点击页面中的 **“安装脚本”**。
4. 浏览器会自动唤起用户脚本管理器，确认脚本内容后点击 **“安装”**。
5. 安装完成后，打开或刷新任意 Bilibili 视频页面即可使用。
